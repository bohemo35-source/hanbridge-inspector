# Body templates (body-sedan/hatchback/compact/city.glb)
Built during the hackathon: concept frame by Meta Muse Image (`muse-image-1.0`, prompts in `scripts/bodies/concepts.mjs`) → Tripo API image-to-3D `v3.1-20260211` (paid API credits, textured PBR, seed 20261102) → `scripts/bodies/optimize.mjs` (03.11: re-built from the Tripo sources at ~150k triangles, WebP 2048, meshopt; before: ~77k, WebP 1024). Panels are found at runtime by geometry (`classifyTriangle` in `src/components/garage-studio/scene.ts`); triangles on a panel border are cut exactly along the classifier planes (`slice.ts`) and shut lines are drawn between panels.

`body-suv.glb` — unbranded crossover: Muse Image concept `hero-car-source.jpg` → Tripo multiview_to_model task `48e7d25e-1a22-4950-9434-a5813f03b0cc` (29.10, already paid, see `provenance.json` v2; no new Tripo credits spent) → `optimize.mjs` ratio 0.4 (~155k triangles). The Kia Sportage model (ASSETS.md) is used only for Kia SUVs; every other SUV gets `body-suv`.
