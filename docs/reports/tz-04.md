The plate box is taken from `segmentImage` ([segment.ts](../../src/lib/agent/tools/segment.ts)).

## What was done

- [image.ts](../../src/lib/meta/image.ts) — `generateImage` (POST /images/generations) and `editImage({image, mask, prompt})` (POST /images/edits, multipart). Mask = inverse of the car mask (white = editable background). The live API does not accept a mask → 1 retry without a mask, `maskUsed:false` in the result.
- [listing.ts](../../src/lib/agent/tools/listing.ts) — tool `makeListingPhoto({carId, photoId, imagePath|imageUrl|image, segment?, outDir?, urlPrefix?})` → `{url, plateHidden, backgroundEdited, rejectedReason?, carMaskDiff, plateBox, width, height, badge, trace}`:
  - plate not found → `url:null`, `rejectedReason:"plate_not_found"`, trace `skipped: plate_not_found`, no file is written;
  - plate hiding is deterministic: box from `segmentImage` +8% on each side, blur sigma 30 (≥25), HANBRIDGE plate (font is fitted to the box width — at the 3/4 angle the first version cut the text down to "NBRID", fixed);
  - background: edits on the photo with the plate hidden (input ≤1024 px, as in smoke), check "car not changed" — mean |difference| per channel inside the car mask, original vs result, threshold 10; above it → result discarded, fallback "plate hidden, original background"; when accepted, the plate is hidden again on the edited frame (the generator may redraw a readable plate);
  - badge: `LISTING_BADGE` / `LISTING_BADGE_NO_BG`; guard `assertFindingsFreeOfListingEvidence` — a listing image in `Finding.evidence` throws an error.
- Hero: `getOrCreateHeroImage(reportId)` — generated once per report, cached in Vercel Blob (`heroes/<id>.png`); without a token — local cache `public/generated/heroes/`.
- [/lab/image](../../src/app/lab/image/page.tsx) (dev + Preview, 404 in production): before/after, diff inside the car mask, plate box, trace; the result is cached as a sidecar JSON, `?fresh=1` — regenerate.
- Scripts: [smoke/image.mjs](../../scripts/smoke/image.mjs), [make-listing.ts](../../scripts/make-listing.ts), [make-hero.ts](../../scripts/make-hero.ts).
