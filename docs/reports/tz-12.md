## Что сделано

- **Плейты** (`scripts/journey-v2/generate-plates.mjs`, дописывает `public/journey-v2/prompts.json`): 4 кадра без машин на переднем плане, горизонт ~42%, глаз 1.5 м: `plate-seoul-bridge.jpg`, `plate-port-ramp.jpg` (корма ro-ro с рампой и светящимся трюмом справа), `plate-vladivostok-quay.jpg` (сопки, вантовый мост в дымке, судно с рампой), `plate-handover.jpg` (дом с гаражом, золотой час).
- **Композитинг** (`src/components/journey-v2/scenes/PlateScene.ts`, режим `plate` в `SceneBlock`): фон — плоскость в пространстве камеры (cover, параллакс ±2% и наезд +4% за блок); `environment` — тот же плейт через PMREM (применяется после загрузки текстуры — синхронный вызов ронял сцену); направленный свет + hemisphere-tint под плейт (ночь холодная / рассвет и золотой час тёплые); невидимый пол `ShadowMaterial` (opacity из конфига 0.38–0.48) + радиальная контактная тень под машиной; машина `car-v2.glb` едет по CatmullRom-пути из `blocks.ts` (PLATES), вибрация кузова, ночью фары (радиальный glow-спрайт в `useCar.ts` — раньше спереди был белый квадрат) + PointLight; на вручении фары гаснут при p>0.82, задние спрайты мигают при 0.88<p<0.94. Отладочный режим `?debug=plate`: GridHelper + жёлтая линия пути + красные точки (`tz12-debug-plate-*`).
- **Порт/трюм**: SAM 3.1 по концепту `ship ramp doorway` дал бокс рампы (см. ниже); готовой маски проёма для окклюзии не вышло, применён разрешённый ТЗ фолбэк: в конце пути (p>0.78) машина уменьшается до 0.05 и затемняется/исчезает у проёма. Кадр конца — `tz12-05b-port-end.png`: машина мала на верху рампы у проёма.
- **Фолбэк код-сцен**: старые `SeoulScene/PortScene/VladivostokScene/FinaleScene` не удалены; `SceneBlock` переключается на них при ошибке загрузки плейта, постер блока — сам плейт.
- **Дорога сверху** осталась 3D: тайлы увеличены до 260 м, 4 зоны (побережье → лес → степь → пригород-приглушённая степь, разный repeat/тинт), `receiveShadow` + контактная тень за машиной, финал-карта без изменений. Гараж и мосты без изменений.
- **Ревью ТЗ-11**: подпись внизу на мостах не показывается (проверено на `tz12-06-sea.png`: только карточки справа/внизу, HUD «Море»); HUD: отзывы и финал — «Доставка» (код + тест порядка блоков). Высоты наращены: сумма `BLOCKS` = **5500vh** (мосты «Море» 450→750, «Подбор»/документы 300→400, Сеул 500→650, Порт 450→600, дорога 450→700). Фактическая высота страницы на скриншотах: 48 600 px при вьюпорте 900 px = **5400vh** (finale/reviews на min-height), при норме 100vh≈3 с это ≈ **2:42–2:45**.

## Что не получилось / ограничения

- **Окклюзия трюма маской SAM не применена**: SAM отдал маску рампы, а не кромки проёма; въезд сделан уменьшением до 0.05 + исчезновением у проёма (разрешённый ТЗ фолбэк). На `tz12-05b-port-end.png` машина стоит у левой кромки проёма, не по центру светящегося трюма: перспектива плоского плейта не даёт увести 3D-машину точно в центр проёма без искажения пути середины блока.
- **Тень**: ShadowMaterial работает только на desktop (shadowMap выключен на mobile в sceneKit), на мобильных остаётся контактный blob. На мокром тёмном асфальте Сеула/Порта blob почти не виден — посадку читают колёса и отражения плейта.
- **Перспектива плейта — приближение**: земля y=0 и путь подобраны по debug-сетке, но фото снято не с нашей камеры; на Владивостоке машина в середине блока крупнее «фото-масштаба» причала (она ближе к нашей камере, чем рампа на фото).
- **Build в основной копии**: живой сервер на :3115 при пересборке портил `.next` (500-ки) — лечится остановкой сервера перед `npm run build`; финальный build прогнан чисто, сервер для capture поднимался после него.
- FPS — только desktop Chrome (GPU metal) и мобильный вьюпорт в том же headless; физического телефона не было.
- `CONTEXT.md`/`PROJECT-STATUS.md` не обновлял: ТЗ-12 разрешает трогать только перечисленные пути; статус по ТЗ-11/12 — в этом отчёте и отчёте ТЗ-11.
