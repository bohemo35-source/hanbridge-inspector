# Отчёт ТЗ-04 — Фото для объявления без номеров (Muse Image)

Ветка `tz-04` от `main` (`f7ec603`). Коммит: `345617a feat(image): listing photos — ...` (+ этот отчёт).
Карта повреждений НЕ делалась (заменена 3D из ТЗ-06) — как указано в задании.
Номерной бокс берётся из `segmentImage` ([segment.ts](../../src/lib/agent/tools/segment.ts)).

## Что сделано

- [image.ts](../../src/lib/meta/image.ts) — `generateImage` (POST /images/generations) и `editImage({image, mask, prompt})` (POST /images/edits, multipart). Маска = инверсия маски авто (белый = редактируемый фон). Живой API маску не принимает → 1 повтор без маски, `maskUsed:false` в результате.
- [listing.ts](../../src/lib/agent/tools/listing.ts) — инструмент `makeListingPhoto({carId, photoId, imagePath|imageUrl|image, segment?, outDir?, urlPrefix?})` → `{url, plateHidden, backgroundEdited, rejectedReason?, carMaskDiff, plateBox, width, height, badge, trace}`:
  - номер не найден → `url:null`, `rejectedReason:"plate_not_found"`, trace `skipped: plate_not_found`, файл не пишется;
  - скрытие номера детерминированно: бокс из `segmentImage` +8% с каждой стороны, blur sigma 30 (≥25), плашка HANBRIDGE (шрифт подбирается по ширине бокса — на 3/4 ракурсе первая версия обрезала текст до «NBRID», исправлено);
  - фон: edits по фото со скрытым номером (вход ≤1024 px, как в smoke), проверка «авто не изменено» — средняя |разница| по каналам внутри маски авто оригинал vs результат, порог 10; выше → результат отброшен, фолбэк «номер скрыт, фон оригинальный»; при принятии номер скрывается повторно уже на отредактированном кадре (генератор может перерисовать читаемый номер);
  - бейдж: `LISTING_BADGE` / `LISTING_BADGE_NO_BG`; гард `assertFindingsFreeOfListingEvidence` — listing-картинка в `Finding.evidence` бросает ошибку.
- Hero: `getOrCreateHeroImage(reportId)` — генерация 1 раз на отчёт, кэш в Vercel Blob (`heroes/<id>.png`); без токена — локальный кэш `public/generated/heroes/`.
- [/lab/image](../../src/app/lab/image/page.tsx) (dev + Preview, в production 404): до/после, diff в маске авто, бокс номера, trace; результат кэшируется sidecar JSON, `?fresh=1` — регенерация.
- Скрипты: [smoke/image.mjs](../../scripts/smoke/image.mjs), [make-listing.ts](../../scripts/make-listing.ts), [make-hero.ts](../../scripts/make-hero.ts).

## Что не работает / ограничения

- Студийный фон на демо не получен: `/images/edits` без маски перерисовывает авто (diff 20–30 > 10), с маской API не работает. Listing-фото = скрытый номер + оригинальный фон. Когда Meta добавит маску в edits, путь принятия уже готов и покрыт тестом.
- Blob-ветка hero не проверена вживую: `BLOB_READ_WRITE_TOKEN` пустой в `.env.local`. Локальная ветка проверена (генерация 23 с, повтор — кэш 0 мс).
- `/lab/image` без sidecar-кэша делает живые вызовы SAM+Image (~20–35 с на фото).
