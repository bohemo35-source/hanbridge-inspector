# demo-data (not tracked)

Real inspection media of the demo cars, one folder per car. Everything except this README is git-ignored.

```
demo-data/<car-id>/              e.g. mini-cooper-s, bmw-530, bmw-x3, mercedes-…, hyundai-sonata
  photos/                        walk-around photos (jpg)
  video/                         walk-around videos, paint_gauge.mp4 (mp4/mov)
  audio/                         inspector voice note (wav), optional
  sheets/                        auction sheet / registration / VIN photos (jpg)
  inspector_report_ru.txt        inspector's written report, optional
  paint.json                     paint-gauge readings, microns: {"hood": 120, ...}, optional
  out/                           generated by scripts (detections, overlays)
```

## Vercel Blob (agent run on Vercel)

The `demo-data` folder is not in git, so on Vercel the agent takes its media from Blob: `demo/<car-id>/...`, with the file map in `src/lib/agent/blob-manifest.json`
(`media.ts`: the local folder takes priority, `MEDIA_SOURCE=blob|local` forces the source).
Upload: `node --env-file=.env.local scripts/upload-demo-to-blob.mjs` (videos are uploaded as light copies, OBD-PDFs without personal data; details in the script header).
Photo index for a new car: `npx tsx --env-file=.env.local scripts/build-photo-index.ts <car-id>` before uploading.
