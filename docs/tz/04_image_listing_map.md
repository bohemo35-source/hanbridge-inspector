# ТЗ-04 — Фото для объявления без номеров (Muse Image)

Сначала прочитай AGENTS.md. Выполни задание целиком; проблемы фиксируй в отчёте.

## Цель
Фото для объявления: номера скрыты, фон приведён к студийному через Muse Image, при этом **сам автомобиль не изменён**. Карту повреждений НЕ делать: её заменяет 3D-карта кузова из ТЗ-06 (`InspectionMap`, со своим фолбэком без WebGL).

## Принцип доверия (важно для жюри)
Отчёт как доказательство всегда использует ОРИГИНАЛЬНЫЕ кадры. Обработанное фото помечается бейджем «Listing image · plate hidden · background edited by Muse Image · vehicle pixels unchanged» и никогда не используется как evidence.

## Что сделать
1. Скрытие номера (детерминированно): боксы `license_plate` из ТЗ-02 → sharp: размытие (sigma ≥ 25) + плашка «HANBRIDGE» поверх, с отступом 8 % от бокса. Если номер не найден — фото не идёт в объявление, в trace `skipped: plate_not_found`.
2. Фон: `src/lib/meta/image.ts` — `editImage({image, mask, prompt})` через /images/edits; маска = инверсия маски автомобиля (SAM target `car`). Промпт: нейтральная светлая студия, мягкая тень, без текста. Если /images/edits не принимает маску или результат меняет авто — фолбэк: только номер скрыт, фон оригинальный. Проверка «авто не изменено»: в коде сравнить пиксели внутри маски авто (оригинал vs результат) — средняя разница > порога → отбросить результат и записать в trace.
3. Hero-изображение для страницы отчёта: `generateImage` через /images/generations (абстрактный фон в стиле бренда, без машин и текста), кэшировать в Blob, генерировать 1 раз на отчёт.
4. Инструмент агента: `make_listing_photo({carId, photoId})` → `{url, plateHidden, backgroundEdited, rejectedReason?}`. Номерной бокс берётся из `segment_image` (ТЗ-02).
5. `/lab/image` (dev only): до/после, разница пикселей в маске авто.
6. `scripts/smoke/image.mjs` — живой /images/generations (1 картинка) + попытка /images/edits; время каждого вызова в выводе.

## Критерии готовности
- tsc / build / lint / vitest зелёные; сырой вывод в docs/reports/tz-04.md.
- `node --check scripts/smoke/image.mjs`; smoke-вывод в отчёте.
- На демо-фото MINI: файл до/после в `docs/reports/assets/` + число «diff внутри маски авто».
- Ни одна картинка от Muse Image не попадает в `Finding.evidence` (тест на схему/сборку отчёта).
