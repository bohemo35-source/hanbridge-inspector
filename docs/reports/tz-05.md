## Что сделано
- `sparkOpen.ts` (@agent: muse-code): клиент Baseten `meta-models/muse-spark-open-1026` (в AGENTS.md обещан, файла не было).
- Схема: `Evidence.type` += `"obd"` (+ `FINDINGS_DRAFT_SPEC`), `Finding.conflict`, `AgentStep {i,argsSummary,why,ok,outputSummary}` (старые поля сохранены), `Report {carId,listingUrl,heroUrl,shipping,mediaUrls,handoffReason}`.

- `orchestrator.ts`: цикл `sparkChat(tools)` ≤16 шагов, независимые вызовы параллельно, дедуп одинаковых вызовов, trace каждого шага; merge по panel+kind (второй независимый источник +0.08 confidence), `conflict` при противоречии с толщиномером.
- `verifier.ts`: каждая находка проверяется open-weight моделью только по её evidence (+вырезка по боксу); fallback на Spark 1.3, модель пишется в trace. Вердикт детерминированный поверх verified; handoff: conf<0.6 или critical с conf<0.7.
- Store: Blob `reports/{id}.json` при токене, иначе `data/reports/*.json`; `/cars`, `/inspect/:carId` (SSE-трасса вживую), `/r/:id` (noindex, OG-картинка, 3D-карта, Unconfirmed, listing, trace, чат ТЗ-01, вкладка «Доставка» JourneyScene compact), hero-кнопка `/inspect/new` → `/cars` (фикс предсуществующей lint-ошибки в JourneyHero).

## Что не работает / честные ограничения
- Время прогона > 90 с: MINI 151 с, Kia 118 с. Узкие места по trace: `read_gauge_video` 72.7 с (батчи кадров Spark + SAM re-read), `transcribe_note` 26–40 с (ASR по 15-сек чанкам), `make_listing_photo` до 31 с (edits Muse Image, на MINI и X3 отклонён diff-гардом >10 — честный фолбэк, фон не тронут).
- Голос: у X3/Audi/Kia агент выбрал видео без диктовки замеров (readings=0); у MINI и BMW 530i замеры извлечены. На X3 из-за этого 0 находок → conf 0.5 → `handoff=true` (правило сработало, но «задняя правая дверь заменена» из текста инспектора Spark-экстрактор отнёс к claims без kind — не закрыто).
- `pdftotext` в окружении нет: сработал fallback pdf-streams (BMW 530i: 29 систем, Kia: 12 систем, 0 fault codes). VIN из потоков не извлёкся (`vin=n/a`), маскировать было нечего.
- `/r/:id` в инкогнито на Vercel Preview не проверено: пуш/PR по ТЗ делает ревьюер; локально отчёт публичен (без логина, noindex). Blob-токен локально пуст → отчёты в `data/reports/` (в .gitignore), на Vercel уйдут в Blob тем же кодом.
- Читаемых номеров в отчёте нет: в `mediaUrls` попадает только listing-фото с размытым/закрытым номером; оригинальные кадры на страницу не отдаются.
