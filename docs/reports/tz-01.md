- **Bug:** sparkJson never passed zod — Spark had no JSON contract and invented fields (`paint_thickness`, `info`, `paint_reading`); report fell back to gauge-only. **Fix:** `src/lib/schema/prompt.ts` (exact shape + example) passed via new `spec` arg of `sparkJson` (system prompt + retry). - Spark findings are deduped against deterministic gauge findings (panel+kind), forced `verified:false` until the TZ-05 verifier, and dropped if evidence does not point to real media (`gauge` / `photo-N`).
- Fallback verdict now supports WALK_AWAY on critical findings. Trace has two steps (gauge + Spark) with real ms.
- `.session.lock` (Muse runtime file) added to .gitignore.
