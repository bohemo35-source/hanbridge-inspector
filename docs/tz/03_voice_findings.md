# ТЗ-03 — Голосовые заметки инспектора → находки с таймкодами

Сначала прочитай AGENTS.md. Выполни задание целиком; проблемы фиксируй в отчёте.

## Цель
Инструмент агента `transcribe_note`: инспектор надиктовывает обход (RU/EN/KO), Muse Voice Transcribe даёт текст, Muse Spark раскладывает его на находки по панелям; каждая находка ссылается на цитату с таймкодом (`Evidence` типа `transcript`).

## Что сделать
1. Запись в браузере: компонент `VoiceNote` (MediaRecorder) → конвертация в WAV 16 kHz mono на клиенте → загрузка в Blob. Также принимать загруженный WAV/M4A (M4A конвертировать в WAV на клиенте через WebAudio decode).
2. `src/lib/meta/asr.ts` — `transcribe(wavUrl)`: скачать WAV с Blob, multipart: `request` = JSON `{model:"muse-voice-transcribe-1.0", audioEncoding:"WAV", mode:"PUSH_TO_TALK"}` + `audio`. Если в ответе есть сегменты/таймкоды — сохранить; если нет — резать WAV на куски по 20 с (по тишине, если просто сделать; иначе ровно) и транскрибировать кусками, таймкод = начало куска. Записать в отчёт, какой вариант сработал.
3. `extractFindingsFromTranscript(segments, vehicle)` → `sparkJson` по схеме `FindingsDraft`: каждая находка обязана содержать `quote` — дословный фрагмент транскрипта и `tStart/tEnd`. Пост-проверка в коде: `quote` должен реально встречаться в транскрипте (нормализация пробелов/регистра), иначе находка отбрасывается и пишется в `trace` как `rejected: quote_not_found`.
4. Нормализация панелей к тому же словарю, что в ТЗ-02 (общий `src/lib/domain/panels.ts`, синонимы RU/EN/KO: «передний бампер», «front bumper», «앞범퍼»…).
5. Инструмент `transcribe_note({mediaId})` → `{transcript, segments, findings}`.
6. `/lab/voice` (dev only): запись → транскрипт с таймкодами → находки, клик по находке подсвечивает цитату.
7. `scripts/smoke/asr.mjs` — живой запрос на `demo-data/audio/*.wav` (если нет — сгенерировать 10-секундный WAV тишины и сообщить, что нужен реальный файл).

## Критерии готовности
- tsc / build / lint / vitest зелёные; сырой вывод в docs/reports/tz-03.md.
- `node --check scripts/smoke/asr.mjs`; smoke-вывод (транскрипт + время ответа) в отчёте.
- Тест: фейковый транскрипт с 3 замечаниями + 1 «галлюцинация» Spark (цитата, которой нет) → в результате 3 находки, 1 отклонена.
- RU-заметка «на заднем левом крыле перекрас, толщиномер двести» → находка `rear_left_fender / repaint` с цитатой (живой прогон, вывод в отчёте).
