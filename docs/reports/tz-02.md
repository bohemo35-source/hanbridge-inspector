## Что сделано

- `src/lib/domain/panels.ts` — словарь панелей перенесён из ТЗ-06:
  `PANELS`/`PanelId`/`PANEL_IDS`/`isPanelId`/`panelLabel` (id и порядок не изменены)
  + `Panel` (= PanelId | "unknown"), `PANEL_VALUES`, `isPanel`.
  В `src/components/damage-map-3d/panels.ts` оставлен реэкспорт; `COLORS`/`panelVisual`
  остались в 3D-файле. Тесты ТЗ-06 проходят без правок (22 теста).
- `src/lib/meta/sam.ts` — `samSegment(image, concept)` (sharp: rotate/EXIF, resize
  inside 1280×1280, JPEG q85, data URL; `metaFetch` `/responses`, timeout 30 c),
  `parseSamText` (формат `<|box;key=value|>` + опциональный `<|mask;…data=H,W,<enc>…|>`),
  декодирование маски, `scaleBox`.
- `src/lib/agent/tools/segment.ts` — `segmentImage({carId, photoId, imagePath|imageUrl, concepts})`,
  концепции параллельно (≤3). Главная машина: наибольший бокс через центр кадра.
  Главный номер: внутри/у нижней кромки бокса машины, соотношение сторон 2–6, наибольший;
  чужие номера отбрасываются. Маски главных экземпляров и колёс сохраняются PNG
  в `public/generated/<carId>/<photoId>-<concept>.png` → `maskRef` в Evidence типа `mask`.
- `src/lib/agent/tools/defects.ts` — `findDefects({carId, photoId, image})`:
  вырезка по главной машине (+5%), ≤1280 px, `sparkJson` с точным контрактом
  (`view`, `panels_visible: Panel[]`, дефекты с боксами в координатах вырезки),
  пересчёт боксов в исходное фото, `Finding` с evidence `frame`, `verified: false`.
- `scripts/inspect-photos.ts` — `npx tsx scripts/inspect-photos.ts <carId> [--limit N]`:
  `demo-data/<carId>/out/photos.json` + оверлеи `out/overlay/<photoId>.jpg`
  (бокс машины тонкий белый, номер жёлтый, дефекты красные с подписью kind/severity,
  маска машины полупрозрачной синей заливкой, если декодирована; sharp + SVG composite).
- `scripts/smoke/sam.mjs` — один живой запрос `license plate` на `photo_243114_0.jpg`.
- Тесты (vitest, без сети): `src/lib/meta/sam.test.ts`, `src/lib/agent/tools/segment.test.ts`.
- Добавлены зависимости: `tsx` (dev), `@meta-sam/parser`. `.gitignore`: `demo-data/*/out/`
  (`public/generated/` уже был).

## Что не работает / замечания

- `wheel` от SAM возвращает также колёса фоновых машин (на парковке до 15) —
  отбора «колёса только главной машины» в ТЗ не требовалось; все экземпляры
  возвращаются в `byConcept.wheel`/`wheels` и сохраняются масками.
- Spark на вырезках нашёл мало дефектов (1 из 8 фото) — это поведение модели,
  не ошибка пайплайна: контракты и пересчёт боксов проверены тестами и структурой `photos.json`.
- В песочнице `npx tsx` падает с `listen EPERM` (IPC-pipe tsx); вне песочницы работает.
  В отчёте команда приведена как есть.
