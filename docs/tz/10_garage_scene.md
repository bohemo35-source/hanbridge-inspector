## Цель
Киношная scroll-сцена премиум-уровня. Наша машина заезжает в чистый современный бокс осмотра, поднимается на подъёмнике, **разбирается на детали**. На каждой детали появляются **реальные замеры толщиномера из отчёта агента**, потом показывается диагностика, машина **собирается обратно** и выводится вердикт.

Это блок 2 общего сценария путешествия (2:45, 8 блоков); биты этой сцены — в таблице ниже.

Уровень — рекламный ролик автопроизводителя, а не игра. Плохо: серые кубы, «пластилин», висящие в воздухе предметы, рывки камеры.

## Ассеты (готовы, не генерировать новые)
- **`public/models/hero-car-parts.glb`** — главная модель, 32 отдельные детали (узлы `tripo_part_0`…`tripo_part_31`), без текстур. Сжата meshopt: `GLTFLoader().setMeshoptDecoder(MeshoptDecoder)` из `three/examples/jsm/libs/meshopt_decoder.module.js`.
- **`public/models/hero-car.glb`** — та же машина одним мешем с PBR-текстурами (meshopt + webp). Используй только для общих планов, если она выглядит лучше. Основная — модель по деталям.

Оси модели по деталям: +X — перёд машины, +Y — вверх. Левый борт = −Z, правый = +Z. Размер ~0.98 × 0.40 × 0.53; отмасштабируй до длины 4.4 м и поставь колёсами на пол.

### Материалы (свои, кодом)
- **Кузов и панели:** `MeshPhysicalMaterial` «металлик с лаком» (clearcoat 1, clearcoatRoughness ~0.05, metalness ~0.6, roughness ~0.35). Цвет — один параметр (`paint` в props).
- **Кабина (`part_8`):** чёрный глянец с тонировкой стёкол, физичное отражение окружения.
- **Колёса:** тёмная резина/металл (одна деталь, без разделения).
- **Фары:** эмиссия + bloom.
- **Днище:** тёмный матовый.
- **Окружение:** `PMREMGenerator` из `RoomEnvironment` или собственной HDR-сцены кодом. Готовые HDRI не скачивать.

## Окружение «бокс осмотра» (кодом, без чужих ассетов)
- **Пол:** тёмный эпоксидный глянец с отражениями (`Reflector` или roughness 0.15–0.25 + env). Отражение машины должно читаться.
- **Освещение:** длинные линейные LED-панели под потолком (emissive-полосы + `RectAreaLight`) и тёплый контровой свет сзади. Лёгкая дымка: туман + полупрозрачные конусы света. Мягкие тени: contact shadow под колёсами.
- **Подъёмник:** двухстоечный, с лапами под порогами. Простой, но аккуратный: фаски, металл, жёлтые предупреждающие полосы.
- **Фон:** шкафы с инструментом и стена — только силуэтами в полутьме, без детализации. Лучше меньше, но чисто.

## Биты по скроллу (секция `500vh`, sticky canvas `100svh`)
| Бит | Доля скролла | Что происходит | Подпись (RU/EN) |
|---|---|---|---|
| 0 | 0–0.15 | Машина заезжает в бокс, фары горят, камера низко сбоку и плавно доворачивает к 3/4 | «Осмотр в Корее» / «Inspection in Korea» |
| 1 | 0.15–0.30 | Подъёмник поднимает машину, камера проходит под днищем | «Фото каждой зоны — перед, борта, салон, днище» |
| 2 | 0.30–0.55 | Разборка: детали плавно расходятся по своим направлениям (с задержкой по очереди, easing), камера медленно облетает | «Разбираем по деталям» |
| 3 | 0.55–0.75 | Замеры: над каждой деталью метка «NNN мкм» (CSS2DRenderer или спрайт). Цвет детали и метки по правилу ≤150 норма, 151–220 перекрас, >220 шпатлёвка. Деталь с находкой подсвечивается | «Толщиномер по каждой детали — перекрас виден цифрой» |
| 4 | 0.75–0.88 | Диагностика: если в отчёте есть evidence `obd`, показать «OBD: N систем, ошибок 0» по данным. Если нет — бит пропускается, без выдуманных цифр | «Двигатель и диагностика» |
| 5 | 0.88–1.00 | Сборка обратно, машина опускается, карточка вердикта: BUY / NEGOTIATE / WALK AWAY, «находок N, подтверждено M», ссылка «Открыть отчёт» → `/r/:id` | «Решение — после отчёта» |

Скролл вниз проигрывает сцену, вверх отматывает точно назад. Камера и детали интерполируются от прогресса без рывков (damping), никакой работы на таймерах.

## Данные — только из отчёта
- Компонент `GarageScene` принимает `{ report?: Report, lang: "ru" | "en", paint?: string, compact?: boolean }`.
- **Замеры:** `report.paintReadings` (panel → microns).
- **Находки:** `report.findings`, только `verified === true`. Неподтверждённые — фиолетовым с пометкой «не подтверждено».
- **Вердикт:** `report.verdict`.
- Детали без замера остаются без метки. Ничего не придумывать.
- Страница `/lab/garage?car=<carId>&lang=ru|en&debug=parts` берёт последний отчёт машины через `listReportsAsync()` (как `/cars`). По умолчанию `mini-cooper-s`. Это страница для записи видео.
- Модель кузова одна для всех машин (шаблон). В подписи сцены марка машины не пишется, только данные.

## Производительность
- Треугольники сцены ≤ 400 000.
- **Desktop:** 60 fps на MacBook M-серии. **Мобильный:** pixelRatio ≤ 1.5, без Reflector (fallback на roughness-пол), bloom выключен.
- **Eco-режим:** если средний FPS за 2 с < 40 — выключить Reflector, bloom и дымку.
- **Lazy:** модель и сцена грузятся при приближении секции к экрану и полностью освобождаются (`dispose`) при уходе далеко.
- `prefers-reduced-motion` / нет WebGL: лента из 6 карточек с теми же подписями и данными замеров.
