- **Живой dev-сервер на :3100** (поднят не этой сессией) делит `.next` с рабочей копией: мой `next build` в основном репо пересобрал `.next`, после чего и :3100, и мои `next start` отдавали HTML с dev-чанками (404). В основной копии после этого `npm run build` повторно не гонял — evidence по build из worktree.
- **Длительность ~2:05 вместо 2:45**: сумма высот блоков по ТЗ = 4250vh (фактически 4150vh из-за секции отзывов на `min-height`), при норме 3 с/100vh целевой длины не хватает. Лечится увеличением высот блоков (500→650vh и т.д.) — цифры высот взяты из таблицы ТЗ без изменений.
- **Порт**: машина заезжает в сторону судна, но геометрия рампы и точки входа в корпус совпадают приблизительно: в середине блока машина у кормы, к концу уходит внутрь и скрывается корпусом; точной посадки колёс на рампу нет.
- **Владивосток**: машина на причале мелковата в середине блока; судно — упрощённый корпус без деталей.
- **Гараж в capture** ронял вкладку Chrome при скролле через несколько WebGL-блоков подряд в одном браузере — capture снимает блоки по одному процессу (`ONLY=`/`SKIP_EXTRA=1`); в обычном скролле пользователя блоки размонтируются по удалению (проверено: `canvases` ≤ 2).
- **Мобильный Сеул**: подпись внизу частично перекрывает кнопку RU→EN; машина крупнее кадра слева.
- FPS измерен только на desktop Chrome (GPU metal); мобильный FPS — тот же headless с вьюпортом 390×844 (60), не физический телефон.
